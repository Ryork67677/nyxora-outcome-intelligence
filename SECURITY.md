# Security Policy

## Scope

This educational repository uses generated synthetic records only. It is not approved for protected
health information, customer contact details, authentication credentials, or production decisions.

## Known limitations

- The local API has no authentication or rate limiting.
- The bundled model artifact is trusted local input and must not be loaded from an untrusted source.
- Docker uses the development-grade single-process server configuration.
- Security, privacy, retention, fairness, and compliance reviews have not been completed.

Please report a suspected vulnerability privately to the repository owner rather than opening a
public issue containing exploit details or secrets.
